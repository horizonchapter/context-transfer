# Sécurité

Ce dépôt ne contient que du Markdown : aucun script, aucune clé. Le skill interdit d'écrire des secrets dans une passation (« [secret retiré] ») : ne mets jamais tes vraies adresses, jetons ou liens privés dans un fork public.

Un problème de sécurité ? Ne l'ouvre pas en issue publique : utilise **Security → Report a vulnerability** sur la page du dépôt.
